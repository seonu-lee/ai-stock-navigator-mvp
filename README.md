# ai-stock-navigator-mvp

AI 기반 초보 투자자 맞춤형 주식 시장 이해 및 투자 인사이트 플랫폼 MVP

---

## 프로젝트 소개

주식 시장에 입문하는 투자자들은 공통적으로 다음 어려움을 경험한다.

- 차트를 봐도 무엇을 봐야 하는지 모른다
- 금융 뉴스를 읽어도 내 투자에 어떤 의미인지 연결이 안 된다
- 종목 추천은 많지만 왜 그 종목인지 이해할 수 없다

이 프로젝트는 단순 종목 추천이 아닌, 투자자 스스로 시장 흐름과 차트를 이해하고 판단을 내릴 수 있도록 돕는 AI 기반 투자 학습 플랫폼 MVP를 목표로 한다.

---

## 핵심 기능 (MVP 범위)

| 기능 | 설명 |
|------|------|
| 시장 브리핑 | 하루 1회 배치, 주요 지수 및 업종 등락 요약 |
| 종목 분석 | 코스피 대형주 중심 20개 종목 기술적 지표 분석 |
| AI 차트 해석 | Rule-based 탐지 결과를 Claude/Gemini API로 자연어 설명 |
| 거래량·수급 분석 | Z-score 기반 이상치 탐지, 외국인·기관 순매수 분석 |
| AI Q&A | 템플릿 기반 질문에 Claude/Gemini API 응답 |
| 산업 네트워크 | 5대 섹터 정적 상관관계 시각화 |

---

## 분석 흐름 요약

```
[1단계] 데이터 수집
    pykrx         → 주요 20개 종목 일별 OHLCV
    pykrx         → 외국인·기관 순매수 데이터
    BeautifulSoup → 네이버 금융 뉴스 크롤링
        |
        v
[2단계] 분석 모델링
    기술적 지표   → 이동평균(5·20·60일), RSI, 볼린저밴드
    이상치 탐지   → 거래량 Z-score 2σ 초과 시 플래그
    감성 분석     → KR-FinBERT 기반 뉴스 감성 점수
    상관관계 분석 → 피어슨 상관계수 기반 섹터 네트워크
        |
        v
[3단계] AI 설명 레이어
    분석 수치·플래그 → 구조화된 프롬프트 변환
    Gemini/Claude API → 초보자 대상 자연어 설명 생성
    면책 고지 자동 삽입
        |
        v
[4단계] UI (Streamlit)
    시장 브리핑 페이지
    종목 분석 + 차트 해석 페이지
    AI Q&A 페이지
```

## 기술 스택

| 영역 | 기술 |
|------|------|
| 데이터 수집 | pykrx, yfinance, BeautifulSoup |
| 데이터 처리 | pandas, numpy, scipy |
| 감성 분석 | KR-FinBERT (HuggingFace) |
| AI 설명 레이어 | Gemini API (무료 티어) / Claude API |
| 시각화 및 UI | Streamlit, plotly |
| 데이터베이스 | SQLite |
| 스케줄링 | APScheduler |

## 주의사항

본 서비스는 투자 교육 및 정보 제공을 목적으로 하며, 특정 종목의 매수·매도를 권유하지 않는다.
AI가 제공하는 분석과 설명은 참고용이며, 실제 투자 결과에 대한 책임은 투자자 본인에게 있다.
모든 투자에는 원금 손실의 위험이 있다.

## 개발 일정 (MVP 6주)

| 주차 | 단계 | 내용 |
|------|------|------|
| 1주차 | 환경 구축 + API 테스트 | 더미 데이터로 API 연동 확인, 프롬프트 초안 설계 |
| 2주차 | 데이터 수집 파이프라인 | pykrx 수집 스크립트, SQLite 적재, 뉴스 크롤러 |
| 3주차 | 분석 모델링 | 기술적 지표, 이상치 탐지, 감성 분석, 섹터 네트워크 |
| 4주차 | AI 설명 연결 | 분석값 → 프롬프트 → API → 자연어 출력 파이프라인 |
| 5주차 | Streamlit UI 구현 | 대시보드 레이아웃, 차트 시각화, Q&A 인터페이스 |
| 6주차 | 검증 및 개선 | 사용자 피드백, 프롬프트 튜닝, 면책 고지 정비 |
